Gamer Briefing

Running dual Diamond Monster 3D II (12MB Voodoo2 SLI) cards on a Pentium II 350MHz? Stop playing in software mode like a caveman! Drop these cvars into quake2\baseq2\autoexec.cfg for silky 64 fps at 1024x768!


Quake II Voodoo2 SLI autoexec.cfg
set gl_driver "3dfxgl"
set vid_ref "gl"
set gl_mode "6"            // 1024x768 Glide
set gl_swapinterval "0"    // Disable vsync cap
set gl_ext_multitexture "1"
set cl_maxfps "72"
set intensity "2.4"        // Brighten dark DM1 corners
