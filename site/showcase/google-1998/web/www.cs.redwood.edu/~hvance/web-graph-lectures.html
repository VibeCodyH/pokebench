CS 404 Lecture Notes: Eigenvectors of the World Wide Web Graph
Prof. Harold Vance | Lecture 7 -- Updated 09-Sep-1998

Today we analyze why power iteration converges rapidly on the Web adjacency matrix. Let M be the column-stochastic hyperlink matrix where M[i,j] = 1/outdeg(j) if page j links to page i. Because real web graphs contain dead ends (dangling nodes) and disconnected components (spider traps), we form the Google matrix G = d*M + (1-d)/N * E with damping factor d = 0.85, ensuring strict positivity and ergodicity.

/* Power iteration loop (N = 500 .. 24,000,000) */
for (iter = 0; iter < MAX_ITER; iter++) {
    dangling_mass = sum(pr[u] for u in dangling_nodes);
    base = (1.0 - 0.85) / N + 0.85 * dangling_mass / N;
    for (v = 0; v < N; v++) next_pr[v] = base;
    for ((u, v) in edges) next_pr[v] += 0.85 * pr[u] / outdeg[u];
    if (l1_norm(next_pr - pr) < 1e-9) break;
}

Since the second eigenvalue magnitude of G is bounded by d = 0.85, the L1 residual shrinks geometrically: 0.85^52 < 0.00022, typically reaching 1e-9 convergence within 50 to 65 passes.
