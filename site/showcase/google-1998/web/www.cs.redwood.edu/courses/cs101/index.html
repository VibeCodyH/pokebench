CS 101: Introduction to C Programming and Unix Shells
Prof. Marcus Sterling | Soda Hall 202, MWF 10:00 AM | Fall 1998

Foundations of ANSI C pointers, dynamic memory with malloc/free, standard I/O, Makefiles, gdb debugging, and Unix tcsh shell pipelines on SPARCstation 5 workstations.

Required Text: Kernighan & Ritchie, The C Programming Language (2nd ed.)
Grading: Programming Projects 50% | Midterm 20% | Final Exam 25% | Lab Participation 5%

ScheduleTopics Covered
Weeks 1-3Unix basics, vi/emacs, gcc -Wall -ansi, types & loops
Weeks 4-7Pointers, arrays, C strings, argc/argv, file I/O
Weeks 8-11Structs, linked lists, malloc/free, gdb core dumps
Weeks 12-14fork(), execvp(), pipes, and mini-shell project
