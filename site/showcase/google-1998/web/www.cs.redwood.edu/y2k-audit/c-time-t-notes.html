Y2K vs Year 2038: struct tm Pitfalls in Legacy C Code
Prof. Elena Rostova | Redwood Y2K Engineering Note

While POSIX 32-bit time_t stores seconds since January 1, 1970 and does not wrap to negative values until January 19, 2038 (03:14:07 UTC), thousands of C programs still break on January 1, 2000 because developers formatted tm->tm_year with "19%02d" instead of "%04d", tm->tm_year + 1900.

/* WRONG: prints '19100' on Jan 1, 2000! */
printf("Year: 19%02d\n", tm_now->tm_year);

/* RIGHT: tm_year is years since 1900 (100 in 2000) */
printf("Year: %04d\n", tm_now->tm_year + 1900);
