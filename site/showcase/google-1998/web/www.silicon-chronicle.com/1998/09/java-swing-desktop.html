Sun Pushes Java 1.2 Beta & Write-Once-Run-Anywhere Applets

PALO ALTO, Calif. -- Sept. 14, 1998 -- Sun Microsystems demonstrated Swing UI components and JIT compiler speedups in the upcoming Java 2 (JDK 1.2) beta on Solaris 2.6 SPARC workstations, promising browser applets that look native on Windows 98, Mac OS 8.1, and X11.

However, 28.8k dialup users remain wary of 400KB Swing JAR downloads compared to snappy HTML tables.
