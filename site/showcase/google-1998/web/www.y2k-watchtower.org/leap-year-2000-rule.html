Is 2000 a Leap Year? Yes (Divisible by 400) -- And Why C Code Gets It Wrong

Gregorian calendar quiz: 1900 was NOT a leap year, 1800 was NOT a leap year, but 2000 IS a leap year because it is divisible by 400! Hundreds of hasty payroll and billing utilities coded the incomplete rule (year % 4 == 0 && year % 100 != 0), dropping Tuesday, February 29, 2000 entirely:

/* CORRECT C90 LEAP YEAR CHECK: */
int is_leap(int year) {
    return (year % 4 == 0) && ((year % 100 != 0) || (year % 400 == 0));
}

Also beware struct tm.tm_year (years since 1900): printing "19%02d", tm.tm_year outputs 19100!
