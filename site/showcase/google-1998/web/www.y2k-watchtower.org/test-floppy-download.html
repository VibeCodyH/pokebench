Building an MS-DOS Y2K BIOS Rollover Test Boot Floppy

Prepare a safe 1.44MB 3.5-inch test diskette using any MS-DOS 6.22 or Windows 95/98 workstation so you can verify CMOS RTC rollover without ever spinning up your C: hard drive:

C:\> FORMAT A: /S
C:\> COPY C:\DOS\DATE.COM A:\
C:\> COPY Y2KTEST.EXE A:\
; Write-protect tab UP (open window) before rebooting!

Record results on paper with system serial number, BIOS revision string, and pass/fail date.
