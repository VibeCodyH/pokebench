> Do I need the August 1998 libglide2x.so snapshot for SLI interleaving?

Check two things: first, make sure the `/dev/3dfx` character device module is loaded
with `chmod 660 /dev/3dfx` (group `video`) so non-root Mesa clients can map PCI
registers; second, set `FX_GLIDE_NO_SPLASH=1` and check the short SLI ribbon cable.

# ls -l /dev/3dfx
crw-rw----   1 root     video    107,   0 Sep 14 19:02 /dev/3dfx
