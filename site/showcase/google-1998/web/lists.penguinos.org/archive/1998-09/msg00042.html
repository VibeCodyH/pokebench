> Redirecting port 80 via ipfwadm on dual-homed 56k Linux gateway...

Don't forget UDP masquerading timeouts for QuakeWorld (`port 27500`) if your
roommates game behind the same 56k gateway! Load `ip_masq_quake.o` or UDP return
packets get dropped between map changes.

# /sbin/modprobe ip_masq_quake
# ipfwadm -F -p deny && ipfwadm -F -a m -S 192.168.1.0/24 -D 0.0.0.0/0
