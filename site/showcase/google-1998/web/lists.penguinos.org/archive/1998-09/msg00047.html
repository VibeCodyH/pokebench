Uploading our Borealis 5.2 bootable CD-ROM mastering script for mirror admins.
Uses `mkisofs 1.12b4` with Rock Ridge (`-R`), Joliet (`-J`), and El Torito
1.44MB floppy emulation (`-b images/boot.img`) tested on Yamaha CDR400t.

mkisofs -R -J -V "BOREALIS_52" -b images/boot.img -c images/boot.cat \
  -o /var/tmp/borealis-5.2-i386.iso /export/borealis-tree/
