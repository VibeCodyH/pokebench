> Booting dropped to single-user shell with UNEXPECTED INCONSISTENCY...

Confirm `/dev/hda2` is mounted read-only (or completely unmounted!) before running
`e2fsck -p -y /dev/hda2`. Never run `e2fsck` on a read-write mounted partition or
you will scramble the block bitmap worse than the power outage did.

# mount -o remount,ro /
# e2fsck -f -y /dev/hda2
/dev/hda2: 41289/262144 files (1.2% non-contiguous)
