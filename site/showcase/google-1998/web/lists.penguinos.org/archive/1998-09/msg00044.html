> Win98 clients fail on Samba 1.9.18p10 with Incorrect password...

Windows 98 enforces encrypted NTLM passwords by default (unlike early Win95).
Add `encrypt passwords = yes` to `/etc/smb.conf` and populate `/etc/smbpasswd`
using `smbpasswd -a username` instead of hacking Win98 registry plaintext flags.

# /etc/smb.conf
[global]
  encrypt passwords = yes
  smb passwd file = /etc/smbpasswd
