> StarOffice 4.0 SP3 crashes immediately on startup against glibc 2.0.7...

Install `libc5-compat-5.4.44.i386.rpm` from the Borealis 5.2 CD and wrap `soffice`
in a two-line shell script exporting `LD_LIBRARY_PATH` to `/usr/i486-linux-libc5/lib`
before invoking the StarOffice binary.

#!/bin/sh
export LD_LIBRARY_PATH=/usr/i486-linux-libc5/lib:/opt/Office40/lib
exec /opt/Office40/bin/soffice.bin "$@"
