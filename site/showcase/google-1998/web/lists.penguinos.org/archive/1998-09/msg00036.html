> Netscape 4.06 Linux libc5 crashes whenever visiting Java applets...

Classic Linux Netscape 4.06 Java JIT bug! Set `export NS_JAVA_JIT=0` before
launching `netscape`, or edit `~/.netscape/preferences.js` to disable the JIT
compiler while keeping Motif 2.0 static binary libraries intact.

user_pref("security.enable_java", true);
/* Launch wrapper: env MOZILLA_HOME=/usr/lib/netscape NS_JAVA_JIT=0 netscape */
