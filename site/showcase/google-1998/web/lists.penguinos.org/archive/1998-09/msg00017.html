> A 1996 Award 4.51PG BIOS rolled straight back to 1900-01-01...

Good catch! Note that Linux kernel `time_t` itself is a 32-bit signed integer since
1970 and won't overflow until Jan 19, 2038, so adding `hwclock --hctosys` after an
`ntpdate` sync (or updating the Award BIOS EPROM) protects Borealis servers cleanly.

/* POSIX time_t max = 2147483647 -> Tue Jan 19 03:14:07 2038 UTC */
