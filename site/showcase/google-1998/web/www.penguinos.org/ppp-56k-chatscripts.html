USRobotics 56k V.90 Modem Init Strings & pppd Chatscripts
Borealis Linux 5.2 Documentation Project | Updated 11-Sep-1998

Connecting USRobotics Sportster 56k V.90 modems to campus Ascend racks occasionally triggers 20-minute carrier drops when V.90 line quality degrades. Locking hardware RTS/CTS flow control with AT&F1 and disabling flaky V.90 negotiation via AT&F1S32=34 stabilizes K56flex/33.6k sessions.

# /etc/ppp/chat-redwood
ABORT BUSY ABORT 'NO CARRIER' ABORT ERROR
'' AT&F1S32=34
OK ATDT5550192800
CONNECT ''
