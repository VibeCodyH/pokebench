Hardening Apache 1.3.1 & mod_perl on Borealis Linux
Borealis Linux 5.2 Documentation Project | Updated 11-Sep-1998

Forking a fresh /usr/bin/perl process per CGI hit caps a Pentium II web server around 15 requests/second. Enabling mod_perl 1.15 inside Apache 1.3.1 keeps the Perl interpreter resident in memory and caches compiled Apache::Registry scripts for a 10x throughput gain.

# /etc/httpd/conf/httpd.conf
KeepAlive On
KeepAliveTimeout 5
Alias /perl/ /home/httpd/perl/
<Location /perl>
  SetHandler perl-script
  PerlHandler Apache::Registry
</Location>
