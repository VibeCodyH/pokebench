SoundBlaster 16 IRQ/DMA & OSS Driver Configuration HOWTO
Borealis Linux 5.2 Documentation Project | Updated 11-Sep-1998

ISA SoundBlaster 16 and AWE64 PnP cards require initialization via isapnptools before loading the OSS sb.o kernel module. Dump your PnP BIOS resource table first, uncomment non-conflicting IRQ/DMA lines, then test /dev/dsp.

# /etc/isapnp.conf excerpt for Creative SB16 PnP
(CONFIGURE CTL0044/123456 (LD 0
  (IO 0 (BASE 0x0220)) (IO 1 (BASE 0x0330)) (IO 2 (BASE 0x0388))
  (INT 0 (IRQ 5 (MODE +E))) (DMA 0 (CHANNEL 1)) (DMA 1 (CHANNEL 5))
  (ACT Y)
))

# /etc/conf.modules
options sb io=0x220 irq=5 dma=1 dma16=5 mpu_io=0x330
