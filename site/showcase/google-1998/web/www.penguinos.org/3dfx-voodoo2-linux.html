3dfx Voodoo2 Glide & Quake II on Linux Mini-HOWTO
Borealis Linux 5.2 Documentation Project | Updated 11-Sep-1998

Unlock hardware-accelerated OpenGL and Glide rendering on 3dfx Voodoo2 (8MB/12MB and dual-board SLI) under Borealis Linux 5.2! Install the 3dfx.o kernel character module so non-root users can open /dev/3dfx safely without running Quake II as root.

# insmod /lib/modules/2.0.35/misc/3dfx.o
# chmod 660 /dev/3dfx && chgrp video /dev/3dfx
$ export MESA_GLX_FX=fullscreen
$ quake2 +set vid_ref glx +set gl_driver libGL.so

Single Voodoo2 reaches 55 fps at 800x600; dual SLI reaches 68 fps at 1024x768.
