DEC 21140 Tulip PCI Ethernet & 100Mbps Full-Duplex Notes
Borealis Linux 5.2 Documentation Project | Updated 11-Sep-1998

PCI Ethernet cards using the DEC 21140 / 21143 Tulip chipset offer rock-solid 100Mbps performance under Linux when using tulip.c v0.89H by Donald Becker. Some 3Com SuperStack switches struggle with MII autonegotiation and require forced media flags.

# /etc/conf.modules -- force 100baseTx Full Duplex (options=12)
alias eth0 tulip
options tulip options=12 debug=1

$ ifconfig eth0 | grep RX
RX packets:984120 errors:0 dropped:0 overruns:0 frame:0
