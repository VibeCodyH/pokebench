Linux 2.1 SMP Kernel Spinlocks & Dual Pentium II FAQ
Borealis Linux 5.2 Documentation Project | Updated 11-Sep-1998

Linux 2.0 relied on a single Big Kernel Lock (BKL) across processors, limiting dual-CPU throughput. The 2.1 development series (2.1.120 in Borealis 5.2) introduces fine-grained spin_lock_irqsave() primitives, SMP-safe VFS locks, and an APIC NMI watchdog to catch deadlocks on dual Pentium II / Tyan Tiger boards.

spinlock_t my_queue_lock = SPIN_LOCK_UNLOCKED;
unsigned long flags;
spin_lock_irqsave(&my_queue_lock, flags);
/* critical section on SMP CPU #0 or #1 */
spin_unlock_irqrestore(&my_queue_lock, flags);

Tip: Compile SMP kernels with SMP = 1 in top-level Makefile and avoid egcs -O6 aggressive loop unrolling on 2.0.35 inline assembly.
