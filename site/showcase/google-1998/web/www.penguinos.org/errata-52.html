Borealis 5.2 Security Advisories & libc5/glibc2 Updates
Borealis Linux 5.2 Documentation Project | Updated 11-Sep-1998

Security advisories and compatibility errata for Borealis 5.2 (September 1998). Apply the imapd buffer overflow patch immediately on mail servers, and install libc5-compat-5.4.44.i386.rpm if legacy binaries like StarOffice 4.0 or Netscape 4.06 segfault against glibc 2.0.7.

ADVISORY-98-09-01: imapd-4.1b remote stack overflow -- UPGRADE to imapd-4.4
ADVISORY-98-09-02: libc5-compat wrapper for /usr/i486-linux-libc5/lib
