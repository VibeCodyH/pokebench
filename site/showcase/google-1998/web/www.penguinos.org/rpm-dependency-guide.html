Managing Borealis Packages with RPM 2.5 & Source Tarballs
Borealis Linux 5.2 Documentation Project | Updated 11-Sep-1998

Borealis Linux 5.2 uses RPM 2.5 for binary package tracking while keeping /usr/local clean for manual ./configure && make install source tarballs. Never pass --nodeps blindly when upgrading glibc2 packages.

$ rpm -qpl apache-1.3.1-2.i386.rpm   # inspect files first
# rpm -Uvh apache-1.3.1-2.i386.rpm   # clean upgrade
$ tar xzvf egcs-1.1b.tar.gz && cd egcs-1.1b && ./configure
