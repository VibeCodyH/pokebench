Borealis Linux Year 2000 Readiness & BIOS RTC Statement
Borealis Linux 5.2 Documentation Project | Updated 11-Sep-1998
Y2K Readiness: Linux kernel time_t counts signed 32-bit seconds since Jan 1, 1970, meaning Year 2000 poses zero kernel rollover risk (POSIX epoch wraps Jan 19, 2038).

However, older Award/AMI PC BIOS real-time clocks (RTC) can boot to 1900 or 1980 after Dec 31, 1999. Verify with hwclock and check CGI scripts for 2-digit Perl localtime() formatting bugs.

# hwclock --set --date="01/01/2000 00:01:00" && hwclock --show
