IBM 370 Assembler Time-Macro Remediation Patterns

Ancient utility subroutines written in IBM System/370 Basic Assembly Language (BAL) frequently invoke TIME DEC, which returns packed-decimal 00YYDDDF in Register 1 (where the high byte is 00, NOT a century byte unless TIMEUSED / STCKCONV or TIME LINKAGE=SYSTEM is specified):

* OLD: TIME  DEC           R1 = 00YYDDDF (FAILS AFTER 1999!)
* NEW: TIME  DEC,LINKAGE=SYSTEM,DATETYPE=YYYYMMDD
*      Returns packed-decimal 0YYYYMMDD in 16-byte area.
