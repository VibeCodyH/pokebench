Using Perl 5 Regular Expressions to Flag Suspicious Date Variables in COBOL

Before paying $400,000 for commercial parsing suites, download legacy source PDS members via FTP to a Borealis Linux box and scan millions of lines in minutes with Perl 5.004 (see PerlMonk 5.004 CGI & Text Processing Archive & Writing a Flat-File Perl 5 CGI Guestbook with flock()):

#!/usr/bin/perl -w
while (<>) {
  next if /^.{6}\*/;  # skip COBOL comment col 7
  if (/PIC\s+9\(6\)|YYMM|MMDDYY|ACCEPT.*FROM\s+DATE/i) {
    print "$ARGV:$.: $_";
  }
}
