COBOL Rescue '99 Opens Redwood Regional Remediation Center

PALO ALTO, Calif. -- Sept. 12, 1998 -- COBOL Rescue '99 today cut the ribbon on a 18,000 sq ft mainframe factory adjacent to Redwood State University, housing an IBM 9672 CMOS Multiprise test bed connected via dedicated OC-3 fiber for rapid client LPAR verification.
