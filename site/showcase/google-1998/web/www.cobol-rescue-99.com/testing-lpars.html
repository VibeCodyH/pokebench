Isolating Future-Date LPARs Without Corrupting Production Payroll

Never test Y2K rollover by changing the system clock on a shared sysplex LPAR -- RACF certificates, DB2 logs, and paycheck runs will expire prematurely! Always provision an isolated Logical Partition (LPAR) with dedicated DASD volumes and SYS1.PARMLIB(CLOCKxx) offset:

/* SYS1.PARMLIB(CLOCK99) FOR LPAR TEST04 */
OPERATOR NOPROMPT
TIMEZONE W.08.00.00
SIMETRID 00   /* ISOLATED ETR CLOCK FOR 1999-12-31 23:55 ROLLOVER */

Coordinate test window schedules using Trusted Y2K Resources, University Audits & Government Bulletins.
