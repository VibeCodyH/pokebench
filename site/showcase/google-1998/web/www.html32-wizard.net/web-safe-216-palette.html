The 216-Color Browser-Safe Palette Reference Chart
HTML 3.2 Wizard | Brenda Sterling-Hayes | 10-Sep-1998

Millions of 1998 PCs still run 256-color (8-bit) VGA displays. Using arbitrary hex colors causes ugly halftone dithering in Netscape. Stick strictly to the 216 browser-safe cube built from hex pairs 00, 33, 66, 99, CC, FF:

#000099#003399#006699#009999#00CC99#00FF99
#660099#663399#666699#669999#66CC99#66FF99
#CC0099#CC3399#CC6699#CC9999#CCCC99#CCFF99
#FF0099#FF3399#FF6699#FF9999#FFCC99#FFFF99
