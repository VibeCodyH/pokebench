Controlling Web Spiders with /robots.txt
HTML 3.2 Wizard | Brenda Sterling-Hayes | 10-Sep-1998

Keep automated web spiders out of infinite calendar scripts, private draft folders, and /cgi-bin/ directories by placing a plain-text /robots.txt file at your web server root.

# http://www.example.org/robots.txt
User-agent: *
Disallow: /cgi-bin/
Disallow: /tmp/
