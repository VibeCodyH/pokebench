Surviving document.all (IE4) vs document.layers (Netscape 4)
HTML 3.2 Wizard | Brenda Sterling-Hayes | 10-Sep-1998

Dynamic HTML in 1998 splits down the middle: Internet Explorer 4 exposes elements via document.all, whereas Netscape Communicator 4 uses document.layers. Wrap any DHTML positioning check in an explicit object-detection branch.

function getLayer(id) {
    if (document.layers) return document.layers[id];
    if (document.all) return document.all[id];
    return null;
}
