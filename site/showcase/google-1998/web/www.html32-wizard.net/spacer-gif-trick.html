The 1x1 Transparent Spacer GIF Technique Explained
HTML 3.2 Wizard | Brenda Sterling-Hayes | 10-Sep-1998

Netscape 4 collapses empty table cells and ignores pixel widths unless content fills the cell. Drop a 43-byte 1x1 transparent GIF89a (spacer.gif) stretched via WIDTH and HEIGHT attributes to lock exact column gutters.

<td width="160" bgcolor="#003366">
  <img src="spacer.gif" width="160" height="1" border="0" alt="">
</td>
