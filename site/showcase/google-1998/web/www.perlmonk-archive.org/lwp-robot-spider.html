Building a Polite Web Spider with LWP::UserAgent and robots.txt
PerlMonk 5.004 Archive | Randall Mercer & Contributors | 09-Sep-1998

Respecting /robots.txt and server crawl delays keeps your university IP block from getting firewalled. Combine LWP::UserAgent with WWW::RobotRules to parse host exclusions automatically before issuing HTTP GET requests.

#!/usr/bin/perl -w
use LWP::RobotUA;
my $ua = new LWP::RobotUA('RedwoodBot/0.9', 'crawl@cs.redwood.edu');
$ua->delay(15 / 60);  # 15 seconds between hits per host
my $res = $ua->get('http://www.penguinos.org/index.html');
print length($res->content) if $res->is_success;

Production Note: Always identify your spider via User-Agent and an active email contact.

Perl 5.004 Environment & Testing Note: Verify scripts from the shell with perl -wcT script.cgi before copying them into /usr/local/apache/cgi-bin. Under Apache mod_perl or standard CGI, inspect /var/log/httpd/error_log with tail -f to catch premature end-of-script-headers and uninitialized $_ warnings.
