Parsing Tab-Delimited Log Files & Generating HTML Tables
PerlMonk 5.004 Archive | Randall Mercer & Contributors | 09-Sep-1998

Turn raw Apache Common Log Format or tab-delimited benchmark tables into clean HTML 3.2 summaries. Escape cell values with CGI::escapeHTML() and alternate row colors for legibility in Netscape 4.

print "<table border=1 cellpadding=4>\n";
while (<LOG>) {
    chomp; my @cols = split /\t/;
    print "<tr>" . join('', map { "<td>" . escapeHTML($_) . "</td>" } @cols) . "</tr>\n";
}
print "</table>\n";

Production Note: Check log rotation boundaries so cron doesn't truncate half-written lines.

Perl 5.004 Environment & Testing Note: Verify scripts from the shell with perl -wcT script.cgi before copying them into /usr/local/apache/cgi-bin. Under Apache mod_perl or standard CGI, inspect /var/log/httpd/error_log with tail -f to catch premature end-of-script-headers and uninitialized $_ warnings.
