Safe Form-to-Email CGI Script Without Shell Escapes
PerlMonk 5.004 Archive | Randall Mercer & Contributors | 09-Sep-1998

Passing user-supplied form email addresses through a shell command like open(M, "|mail $to") lets attackers inject ; rm -rf /. Invoke /usr/sbin/sendmail -t -oi via a piped fork/exec under -T taint mode.

#!/usr/bin/perl -wT
use strict;
$ENV{PATH} = '/usr/sbin:/usr/bin';
my $pid = open(MAIL, '|-');
defined($pid) or die "fork failed: $!";
exec('/usr/sbin/sendmail', '-t', '-oi') unless $pid;
print MAIL "To: webmaster\@cs.redwood.edu\nSubject: Feedback\n\n$clean_msg\n";
close(MAIL);

Production Note: Zero subshell execution means zero shell metacharacter exploits.

Perl 5.004 Environment & Testing Note: Verify scripts from the shell with perl -wcT script.cgi before copying them into /usr/local/apache/cgi-bin. Under Apache mod_perl or standard CGI, inspect /var/log/httpd/error_log with tail -f to catch premature end-of-script-headers and uninitialized $_ warnings.
