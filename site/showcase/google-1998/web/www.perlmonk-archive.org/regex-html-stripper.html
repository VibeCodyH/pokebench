Regular Expressions for Stripping HTML Tags & Extracting Links
PerlMonk 5.004 Archive | Randall Mercer & Contributors | 09-Sep-1998

When indexing crawled HTML documents in Perl, naive regexes like s/<.*?>//g fail on multiline tags, HTML comments, and unquoted attributes. Match comments first, extract <A HREF> targets and anchor text, then normalize whitespace.

#!/usr/bin/perl -w
use strict;
while ($html =~ m{<a\s+[^>]*href\s*=\s*"([^"]+)"[^>]*>(.*?)</a>}gis) {
    my ($url, $anchor) = ($1, $2);
    $anchor =~ s/<[^>]+>//g;
    print "$url => $anchor\n";
}

Production Note: Note: Always inspect HTML comments before stripping tags so <!--#exec--> doesn't leak.
