Why Every CGI Script Needs 'use strict;' and -w
PerlMonk 5.004 Archive | Randall Mercer & Contributors | 09-Sep-1998

Unexplained silent bugs in 300-line Perl CGI scripts almost always trace back to typos in global variable names. Adding use strict; and #!/usr/bin/perl -w catches misspelled scalars and uninitialized values immediately in Apache's error_log.

#!/usr/bin/perl -w
use strict;
my $user_count = 0;
$user_cout++;   # Compile-time error under 'use strict' instead of silent bug!

Production Note: Zero excuse to omit -w and use strict in any Perl 5 script written in 1998.

Perl 5.004 Environment & Testing Note: Verify scripts from the shell with perl -wcT script.cgi before copying them into /usr/local/apache/cgi-bin. Under Apache mod_perl or standard CGI, inspect /var/log/httpd/error_log with tail -f to catch premature end-of-script-headers and uninitialized $_ warnings.
