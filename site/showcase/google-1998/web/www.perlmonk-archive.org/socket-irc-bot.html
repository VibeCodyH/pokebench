Simple IO::Socket::INET IRC Channel Logger Bot
PerlMonk 5.004 Archive | Randall Mercer & Contributors | 09-Sep-1998

Log channel discussions on EFnet #linux or #starquest using a 35-line IO::Socket::INET bot. Respond to server PING keepalives immediately or the IRC server drops your TCP socket within 90 seconds.

use IO::Socket;
my $s = IO::Socket::INET->new('irc.efnet.net:6667') or die $!;
print $s "NICK logbot98\r\nUSER logbot 0 * :Archive\r\nJOIN #linux\r\n";
while (<$s>) {
    print $s "PONG $1\r\n" if /^PING :(.+)/;
    print LOG $_;
}

Production Note: Avoid flooding channels or EFnet operators will K-line your campus subnet.

Perl 5.004 Environment & Testing Note: Verify scripts from the shell with perl -wcT script.cgi before copying them into /usr/local/apache/cgi-bin. Under Apache mod_perl or standard CGI, inspect /var/log/httpd/error_log with tail -f to catch premature end-of-script-headers and uninitialized $_ warnings.
