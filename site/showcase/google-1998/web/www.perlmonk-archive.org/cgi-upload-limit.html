Handling Multipart File Uploads Safely in CGI.pm 2.42
PerlMonk 5.004 Archive | Randall Mercer & Contributors | 09-Sep-1998

Accepting file uploads via <INPUT TYPE="FILE"> in CGI.pm 2.42 requires ENCTYPE="multipart/form-data" and a strict $CGI::POST_MAX byte limit so malicious visitors cannot fill your /tmp partition.

#!/usr/bin/perl -wT
use strict;
use CGI;
$CGI::POST_MAX = 1024 * 512;  # 512 KB cap
$CGI::DISABLE_UPLOADS = 0;
my $q = new CGI;
my $fh = $q->upload('patchfile');

Production Note: Validate uploaded MIME bytes instead of trusting client filenames.

Perl 5.004 Environment & Testing Note: Verify scripts from the shell with perl -wcT script.cgi before copying them into /usr/local/apache/cgi-bin. Under Apache mod_perl or standard CGI, inspect /var/log/httpd/error_log with tail -f to catch premature end-of-script-headers and uninitialized $_ warnings.
